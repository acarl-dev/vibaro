- `minimal-hero.jpg` (optional)

## Bildanforderungen

- Format: JPG oder WebP
- Qualität: Hoch, aber komprimiert (<500KB pro Bild)
- Hero-Bilder: 2100x900px (21:9) oder 1920x1080px (16:9)
- Release Covers: 500x500px (1:1)
- Gallery: Variabel, mindestens 800px auf der längsten Seite
- Avatar: 400x400px (1:1)

## Hinweise

- Bilder sollten keine echten Künstler zeigen
- Abstrakte oder generische Motive bevorzugen
- Farblich zum jeweiligen Template passend
