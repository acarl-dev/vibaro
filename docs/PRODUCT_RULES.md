# Vibaro Product Rules (MVP)

## Plans
### Free
- Public musician page
- Basic profile (name, bio)
- Limited themes/variants
- Vibaro branding visible
- No shows/releases in Free (MVP rule)

### Artist (paid)
- Shows + releases enabled
- More themes/variants
- Branding removed
- Basic stats (later)

## Publishing Rules
- Public page is visible only when `is_published = true`.
- Handle must be unique and URL-safe.

## UX Principles
- Defaults must look good immediately after signup.
- No aggressive popups. Upgrade nudges are calm and contextual.

## Out of Scope
- AI features
- Mobile app
- Complex analytics dashboards
- Multi-user teams

## Definition of Done (for features)
- Works on mobile
- Handles empty states
- Uses theme variables (no hardcoded colors)
- Has API contract + validation
